📌 Advanced AI Chatbot
An AI-powered chatbot using OpenAI's DialoGPT model for intelligent, context-aware conversations — built with a Python backend (Flask) and React frontend.

🚀 Features
🤖 Natural language conversations using DialoGPT-medium

🌐 Full-stack app with React frontend and Flask backend

🔄 Real-time message exchange with REST APIs

☁️ Firebase-hosted frontend

🛠️ Technologies Used
Frontend: React, Vite, JavaScript, HTML/CSS

Backend: Python, Flask, Transformers, Torch

Deployment: Firebase Hosting (frontend), Render/Railway (backend)

Tools: Git, VS Code, Postman.

🧪 Running Locally:
Backend (Flask API):
cd backend
pip install -r requirements.txt
python improved_chatbot.py

Frontend (React app):
npm install
npm run dev
